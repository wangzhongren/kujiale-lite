goal: |
  在本地可启动的 Web 应用中交付一个「酷家乐简易版」：用户注册登录后，在浏览器里绘制 2D 户型（墙、房间、门窗），一键生成简易 3D 空间并可切换视角漫游；从内置家具/材质库拖拽摆放家具、替换地面与墙面材质；保存方案并在方案列表中重新打开；生成只读分享链接；按房间统计面积与家具数量并导出 CSV。第一版以单机部署、单人使用为边界，聚焦「画得出、看得见、存得下、导得出」的完整闭环。
scope: |
  包含：1) 账号：本地注册/登录与会话，方案数据按用户隔离（认证边界需在文档写清）；2) 户型编辑器：拖拽画墙、墙体连接成闭合房间、添加/移动/删除门与窗、选中/移动/删除对象、撤销/重做；3) 3D 预览：由同一份 2D 数据生成三维墙体与地面，轨道相机与第一人称/漫游视角切换；4) 家具与材质：内置不少于 8 件基础家具与 6 种地板/墙面材质，支持拖拽放置、旋转、删除与材质替换；5) 方案管理：新建、命名、保存、列表、打开、删除；6) 分享：生成只读分享链接，访客无需登录可查看 2D/3D 与只读清单；7) 清单导出：按房间输出面积、家具数量与材质用量，导出 CSV；8) 内置 1 套可直接打开的样板间。
  不包含：照片级/GPU 光线追踪渲染与云渲染队列；真实商品库、下单支付与真实报价引擎；多人实时协同与评论批注；移动端 App；CAD/施工图导出；AI 自动布局；第三方登录、短信验证与对象存储/CDN（如需替代实现，须在 README 写清边界与限制）。
acceptance: |
  质量档位：生产档（客户未指定，按默认生产档执行，不放宽）。
  1) 功能闭环：验收时从注册登录开始，依次完成新建方案→绘制含至少 2 个房间与门窗的户型→生成 3D 并漫游→放置并旋转家具、替换材质→保存→退出重登后从列表打开→生成只读分享链接→导出 CSV，全流程可现场演示，无占位、无 TODO、无假数据。
  2) 正确性：墙体闭合判定、门窗开洞、房间面积计算与 CSV 数值可人工核对；非法输入（空方案名、超长文本、非法坐标、重复注册）有明确提示与一致错误码；2D 与 3D 使用同一份几何数据，不出现两套不一致模型。
  3) 健壮性：方案保存为原子写，进程重启后数据可恢复；并发保存/重复提交有明确策略；上传或导入数据有大小与格式上限。
  4) 安全：密码加盐哈希存储，不记录明文与密钥；会话与权限校验覆盖所有方案读写接口，用户不能读取他人方案；只读分享链接不可被用于修改；防注入/XSS/路径穿越；负例测试覆盖未登录访问、越权访问、非法分享令牌。
  5) 可维护性与架构：模块边界与依赖方向清晰、无循环依赖；README 含启动命令、架构说明、API、权限模型、数据 schema 与状态机、已知限制与权衡；数据 schema 与 API 契约有版本/迁移/兼容说明；新增家具类型、材质、导出字段时写明扩展点。
  6) 可观测性：关键失败（登录失败、保存失败、渲染异常、导出失败）有结构化日志与可读错误信息，不静默吞错。
  7) 性能与容量：方案列表分页，单方案对象数量与几何点数有上限并给出已知容量边界；页面加载/切换有加载态、空态与错误态。
  8) 前端体验：加载/空/错误三态齐备；编辑器键盘可用（删除、撤销），主要控件有标签、对比度满足基本可访问性；窄屏（≥375px）可查看方案与只读分享页。
  9) 测试：单元+集成+端到端测试矩阵齐备，权限与非法路径必须有负例；测试独立于实现，不为保绿弱化断言。
  10) 交付演示：验收前必须真实启动应用，提供启动命令、访问地址与截图/录屏，并现场走通第 1 条全流程；未真实运行不得建议验收通过。
